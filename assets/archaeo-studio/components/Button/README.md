# Button

글자 단추. 높이 28, 모서리 7, 글자 12px이 기본입니다.

- 받는 것: 글자, `variant`, `size`(`md` 28 · `lg` 36), `icon`, `block`, `disabled`, `onClick`.
- `default`: 평범한 동작(파일 불러오기, 잠시 멈춤, 그만두기). `tab` 바탕.
- `quiet`: 투명. 덜 중요한 보조 동작(작성 전 「PDF로 내보내기」).
- `strong`: 먹색. 대화상자의 확정 단추 하나(「내보내기」).
- `accent`: 흙색. **한 화면에 하나**, 고른 문서 종류의 실행 단추에만. 다른 쪽 실행 단추는 `default`.
- `lg`(36)는 실행 단추 둘에만 씁니다.
- 「확인」 「취소」 대신 하는 일을 씁니다: 「내보내기」 「그만두기」 「닫고 계속하기」.
