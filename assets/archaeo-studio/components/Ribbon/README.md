# Ribbon

WordCraft 리본: 파일 · 홈·서식 · 삽입 · 스튜디오 · 내보내기. 높이 86, 타일 58, 아이콘 칸 46×40·모서리 9.

- 받는 것: `Ribbon`(`search`) › `RibbonGroup`(`caption`) › `RibbonTile`(`icon`, `label`, `state`, `dropdown`, `disabled`). 앱 리본 그대로는 `StudioRibbon`(`studioOpen`).
- 「스튜디오」 타일은 왼쪽 패널을 열고 닫습니다. 열려 있으면 `selected`(oat).
- 「PDF 변환」은 누를 때만 PDF를 만듭니다. 저장은 늘 .docx.
- 리본 타일에는 흙색을 쓰지 않습니다(흙색 단추는 실행 단추 하나).
