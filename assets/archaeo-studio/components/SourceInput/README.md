# SourceInput

자료 넣기: 붙여 넣는 여러 줄 칸 + 「파일 불러오기」 + 불러온 파일 칩.

- 받는 것: `label`, `placeholder`, `value`/`defaultValue`, `onChange`, `rows`, `files`(`{name, size, onRemove}`), `onPick`, `accept`(기본 `.docx .pdf .txt .md .csv`), `optional`, `note`.
- 3단계는 꼭 넣는 자료, 4단계는 `optional`. 비어 있으면 「비워 둠」 태그만 붙고, 오류로 보지 않습니다.
- 4단계 아래 안내는 그대로 둡니다.
- 하지 말 것: 빈칸을 붉게 칠하거나 채우라고 재촉하기.
