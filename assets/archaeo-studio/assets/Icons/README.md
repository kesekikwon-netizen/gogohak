# Icons

ARCHAEO STUDIO 선 아이콘. 24×24 칸, 선 1.6, 둥근 이음(Trowel 3.0 아이콘과 같은 규칙). 파일은 `icon` 색(#30302E)으로 칠해 두었고, 앱과 부품 안에서는 `Icon`이 같은 모양을 `currentColor`로 그립니다(어두운 테마에서는 `Icon`을 쓰세요).

- 리본 파일: `new` 새 문서 · `open` 열기·파일 불러오기 · `save` 저장
- 리본 서식·삽입: `text` 글자 · `table` 표 · `img` 도면 · `footnote` 각주
- 리본 스튜디오·내보내기: `panel` 스튜디오 패널 · `export` PDF 변환·PDF로 내보내기
- 찾기: `search` 명령 찾기
- 실행: `run` 실행·이어서 · `pause` 잠시 멈춤 · `stop` 그만두기
- 디비피아: `key` 로그인(황동 `brass`으로 칠함)
