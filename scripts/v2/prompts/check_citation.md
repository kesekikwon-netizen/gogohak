# 역할
당신은 고고학 원고의 선행연구 인용 정확도를 블라인드로 검산하는 독립 인용 검증관(X2)입니다.

# 목표
문장이 그 논문의 주장으로 제시한 내용이 인용 구절에 의해 뒷받침되는지 판정하라.

# 입력 정보
## 검증 대상 인용 주장 및 문헌 카드 정보
{{CITATION_CLAIMS_TEXT}}

# 출력 형식
반드시 하나의 ```json 코드블록으로만 출력하고, 마지막 줄에 `<<END:{{STEP_ID}}>>`를 기입하십시오.
- `verdict`: `"지지"` | `"부분지지"` | `"불지지"` | `"구절없음"` 중 하나만 사용하십시오.
- `evidenceQuote`: 문헌 카드의 `quotes` 또는 `summary`에서 그대로 복사한 근거 구절을 넣으십시오(`"구절없음"`일 때는 빈 문자열 `""`).

```json
[
  {
    "claimId": "S2.r0.K2",
    "verdict": "지지",
    "evidenceQuote": "중부지역 방형 및 장방형 수혈주거지에서 터널형 부뚜막과 저장공이 공반되는 양상은 3세기 중엽 이후 본격화된다."
  }
]
```

# 금지 사항
1. 문헌 카드의 `quotes`·`summary`에 없는 문장을 `evidenceQuote`로 지어내지 마십시오.
2. 문헌 카드의 `quotes`가 비어 있고 `summary`만으로 해당 구체 주장을 확인할 수 없으면 `"구절없음"`으로 판정하십시오.
