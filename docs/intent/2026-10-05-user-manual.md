# 요청 기록: Strata 사용설명서 만들기

- 날짜: 2026-10-05
- 상태: 확정
- 관련 문서: 없음

## 요청 원문
> 사용설명서 제작 추가

## 문제
- 처음 쓰는 사람을 위한 안내는 `docs/user/quick-start.md` 한 장뿐이다. 글만 있고 화면 그림이 없다.
- 나머지 `docs/user/` 문서는 기능별 짧은 메모이고, 일부는 개발용 메모다(아이콘·오류 문구 기준·시험 시나리오).
- 앱 안에서 설명서를 여는 곳이 없다(「더보기」에는 「정보」만 있다).
- 포터블에는 `docs/user/` 폴더가 .md 파일 그대로 들어가, 일반 사용자가 열어 보기 어렵다 (추측).

## 바라는 결과
- 현장 조사원이 처음부터 끝까지 따라 할 수 있는 사용설명서 한 권이 생긴다.
- 앱과 포터블에서 바로 열 수 있다.

## 영향받는 곳
- 새 문서(설명서)와 그 그림, 「더보기」 메뉴, 포터블 폴더 구성.

## 지켜야 할 것
- 화면 이름·단추 글자는 지금 앱(새 모양) 그대로 적는다.
- 그림에 API 키·계정·개인 조사 자료가 보이지 않게 한다. 견본 조사(시험용 복사본)로 찍는다.
- 제출 규칙(EPSG:5179 SHP + PDF + MANIFEST.sha256), 작업 좌표계(5186·5187) 같은 정해진 규칙과 어긋나지 않게 쓴다.

## 이번에 하지 않는 것
- 영어판, 동영상 강좌.
- 앱 기능 변경(설명서를 여는 메뉴 하나만 더한다).

## 미정 질문
1. 설명서 형태 — 추천: 화면 그림이 들어간 PDF 한 권. 앱 「더보기 → 사용설명서」로 열고 포터블 폴더에도 넣는다 — 사용자 답: 「1」(2026-10-05) → 추천대로 PDF
2. 내용 범위 — 추천: ① 처음부터 제출까지 한 흐름(새 조사 → 배경 지도 → 그리기 → 저장 → 도면 → 검수·제출) ② 기능별 찾아보기(자료 받기·배경 지도·시굴격자·단면도·정합·내보내기) ③ 자주 막히는 곳(키 넣기, 지도가 안 보일 때 등) — 사용자 답: 추천대로 (2026-10-05)
3. 화면 그림 — 추천: 단계마다 실제 앱 화면(새 모양) 캡처를 넣고, 누를 곳에 번호 표시 — 사용자 답: 추천대로 (2026-10-05)
4. 읽는 사람 — 추천: 처음 쓰는 현장 조사원. GIS 용어는 쉬운 말로 풀어 쓴다 — 사용자 답: 추천대로 (2026-10-05)

## 확인 방법
1. 앱 「더보기 → 사용설명서」를 누르면 설명서가 열린다.
2. 설명서만 보고 새 조사를 만들어 조사구역을 그리고 저장까지 따라 할 수 있다.
3. 포터블 폴더 안에도 같은 설명서가 있다.
