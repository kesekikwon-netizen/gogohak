## 항목별 사실·바라는 결과

### 1. 잘못 붙인 필지 지우기
- 사실: 「지적도 · 복사한 필지」는 지적도 역할이라 Delete·Ctrl+Z가 막혀 있다. 지적도 거부는 네 곳(KaEditUndoOrder.cpp:28, MainWindowUndo.cpp:536, LayerOps::runEditCommand, firstMatchingSurveyLayer).
- 바라는 결과: 도형선택으로 잘못 붙인 필지를 골라 Delete 하면 그 필지만 지워진다. Ctrl+Z 한 번이 Ctrl+V 한 번(여러 필지 포함)을 되돌린다.
- 지킬 것: 받은 지적도 원본은 여전히 고칠 수 없다. 복사본만 지우고 되돌릴 수 있다. 저장한 뒤에는 붙이기를 Ctrl+Z로 되돌릴 수 없고 Delete로 지운다(상태 줄에 알림).

### 2. 수치지형도 등고선 높이 숫자
- 사실: 수치지형도 등고선은 글자가 꺼져 있다(09-21 화면 끊김 때문에 뺌, 9f57a8d). 측량 등고선은 계곡선(5줄마다)에만 붙는다. 높이 칸(elevation)은 이미 있다.
- 바라는 결과: 등고선에 해발높이 숫자가 보인다(아래 질문 1).
- 지킬 것: 지도를 움직일 때 끊기지 않는다(글자가 지번·유구 이름을 밀어내지 않게 우선순위를 낮춘다). 도로·하천 선에는 붙지 않는다.

### 3. DEM 고도 지도 범례 100 m
- 사실: 범례 눈금이 0·100·200·500·1000·1500·2000으로 고정이다. 「현재 화면 맞춤」에서는 임의의 값으로 나뉜다.
- 바라는 결과: 「현재 화면 맞춤」 범례가 100 m 단위로 나온다. 높이차가 300 m 미만인 좁은 곳은 50·20·10 m 단위로 나온다. 전국 표준 범례는 그대로 둔다.

### 4. 유적 번호 고정
- 사실: 도면의 주변 유적 번호는 그 도면 범위 안 유적만 1번부터 매긴다. 도면을 옮기거나 한 장 더 만들면 같은 유적의 번호가 바뀐다(docs/user/layout-heritage-numbers.md).
- 바라는 결과: 같은 유적은 그 조사의 어느 도면에서나 같은 번호다(아래 질문 2).
- 지킬 것: 원본 유적 자료는 바꾸지 않는다. 번호표는 조사 파일 안에 저장한다.

### 5. 새 기능: 유구 등록부
- 사실: 유구는 기록 카드에서 하나씩만 볼 수 있다. 모든 유구를 한눈에 보는 목록이 없다.
- 바라는 결과: 그린 유구 전체가 표로 나온다(아래 질문 4).
- 지킬 것: 조사 자료는 지금처럼 기록 카드에서 고친다. 등록부는 보기·찾기·내보내기용이다.
- 이번에 하지 않는 것: 토층도·층위 관계도(10-10 단면도 삭제와 겹쳐 따로 묻는다), 참조 자료 센터, 제출 준비 시트, 출력 점검.

### 6. 어두운 화면(다크 모드)
- 사실: 밝은 색만 있다. 「화면 보기」에는 고대비·큰 글씨만 있다. 새 모양 기준서(§7)는 다크를 빼 두었다.
- 바라는 결과: 원할 때 어두운 화면으로 바꿀 수 있다(아래 질문 3).
- 지킬 것: 지도 기호 색, 도면 용지, 제출 PDF 결과는 바뀌지 않는다.

### 7. 사용설명서
- 2026-10-05 기록대로 만든다(확정): 그림이 들어간 PDF 한 권, 「더보기 → 사용설명서」와 F1로 열기, 포터블에도 넣기. 단면도는 삭제됐으므로 뺀다. 위 기능이 다 들어간 뒤 마지막에 화면을 찍는다.

### 8. GitHub 저장소 비공개 전환(계정 일)
- 사실: 저장소 kesekikwon-netizen/hgis와 조직 사본 http-www-dong-guk-or-kr/hgis는 공개다. 비공개로 바꾸면 무료 자동 검사 시간이 월 약 2,000분으로 줄고, Windows 검사는 두 배로 센다(추정). 한 번 올릴 때 Windows 검사가 약 80분이라 지금처럼 올릴 때마다 돌리면 며칠 만에 바닥난다.
- 바라는 결과: 아래 질문 5의 답대로.

## 미정 질문
1. 등고선 높이 숫자를 어떻게 붙일까요? — 추천: 평소에는 굵은 계곡선(5줄마다)에만 붙이고, 지도를 크게 확대하면(약 1:1,000보다 가까이) 모든 선에 붙인다. 레이어 목록에서 끌 수 있게 한다. 다른 답: 모든 선에 늘 붙이기 / 계곡선에만 붙이기 — 사용자 답: 「진행」(추천 답 적용)
2. 유적 번호를 조사 전체에서 고정할까요? — 추천: 예. 같은 유적은 어느 도면에서나 같은 번호(가나다순)이고, 한 도면에 3·7·12처럼 건너뛴 번호가 생긴다. 다른 답: 지금처럼 도면마다 1번부터(이 항목을 닫는다) — 사용자 답: 「진행」(추천 답 적용)
3. 어두운 화면은 어디까지 어둡게 할까요? — 추천: 「화면 보기」에 「어두운 화면」 체크를 두고 기본은 지금처럼 밝게 한다. 시작·홈 화면과 리본·패널만 어둡게 하고, 지도·도면 용지·제출 PDF는 그대로 둔다. — 사용자 답: 「진행」(추천 답 적용)
4. 유구 등록부는 어떻게 보일까요? — 추천: 리본 「기록」에 「유구 등록부」 단추를 두고, 누르면 표 창이 열린다(번호·종류·시대·면적·둘레·메모). 줄을 누르면 지도가 그 유구로 이동하고, 표를 엑셀용 CSV로 저장할 수 있다. 고치기는 기록 카드에서 한다. — 사용자 답: 「진행」(추천 답 적용)
5. GitHub 저장소를 비공개로 바꿀까요? — 추천: 예, 비공개로 바꾼다. 대신 Windows 전체 검사는 올릴 때마다가 아니라 하루 한 번(바뀐 날)과 손으로 누를 때만 돌리고, 빠른 점검은 올릴 때마다 돌린다. 조직 사본도 비공개로 바꾼다. 다른 답: 공개 유지 — 사용자 답: 「진행」(추천 답 적용). 계정 설정 변경이라 실행 직전에 한 번 더 확인한다.

## 진행 순서 (기술 결정)
필지 지우기 → DEM 범례 → 등고선 높이 → 유적 번호 → 유구 등록부 → 어두운 화면 → 사용설명서(마지막에 화면 촬영). 저장소 비공개는 답을 받는 대로 따로 한다. 기능마다 시험 먼저 → 빌드·해당 시험·스모크 → 검토 한 번 → 커밋 → main·푸시. 기존 시험 기댓값이 바뀌면 커밋에 「시험 변경:」을 쓰고 보고 맨 위에 알린다.

## 확인 방법
- 필지: 붙인 필지를 골라 Delete → 그 필지만 사라짐, Ctrl+Z → 붙이기 취소. 받은 지적도는 Delete로 안 지워짐.
- 등고선: 수치지형도를 올리고 축척을 바꿔 가며 숫자가 계곡선/모든 선에 나오는지, 지도 움직임이 끊기지 않는지.
- DEM: 「현재 화면 맞춤」 범례가 100 m 단위.
- 유적 번호: 도면 두 장(범위 다름)에서 같은 유적이 같은 번호.
- 유구 등록부: 표에 모든 유구, 줄 클릭 시 지도 이동, CSV 저장.
- 어두운 화면: 체크하면 홈·리본·패널이 어두워지고, 지도·도면·PDF는 그대로. 껐다 켜도 기억.
- 사용설명서: 더보기 → 사용설명서 / F1 로 PDF 열림.
