## 2. 하네스(4장) 및 교차검증(7장) 시나리오별 검증 결과

### 2.1 사전 자가진단 (`H0` / `selftest.js`) 및 감독기 (`supervisor.js`)
1. **시간 초과 → 재시도 → 복구**:
   - 1차 호출에서 `E_GEMINI_TIMEOUT` 발생 시 지수 백오프 후 새 대화로 재시도하여 정상 통과 확인 (`tests/harness.test.js` Subtest 1).
2. **재시도 소진 및 비재시도 오류 즉시 중단**:
   - `E_GEMINI_AUTH`, `E_DOM_DRIFT`, `E_GATE` 등 비재시도 오류 발생 시 재시도 없이 즉시 `needs-human` 상태로 전환 확인 (`tests/harness.test.js` Subtest 2).
3. **체크포인트 기반 중단 후 재개 (`checkpoint.js`)**:
   - `P1`~`P3` 완료 후 프로세스 중단 시 `checkpoint.json` 및 산출물 파일 무결성 검증을 통해 이미 완료된 단계는 건너뛰고 미완료 절(`P4_P5`)부터 정확히 재개 확인 (`tests/harness.test.js` Subtest 3).
   - 산출물 JSON 파일이 손상된 경우 `done` 기록이 있더라도 자동으로 재실행함을 확인.
4. **동시 실행 잠금 (`acquireLock`)**:
   - 살아 있는 PID가 `.lock`을 보유 중일 때 두 번째 작업 요청을 `E_CONCURRENT_JOB`으로 즉시 거부하고, 종료된 PID의 고아 잠금은 자동 회수함을 확인 (`tests/harness.test.js` Subtest 5).

### 2.2 결정적 검사 (`V1`~`V8`) 및 합의 규칙 (`consensus.js`)
1. **결정적 검사 `V1`~`V8`**:
   - `V1`(미표식 수치), `V2`(미표식 인용), `V3`(없는 카드 ID), `V4`(카드에 없는 수치 날조), `V5`(미검증 문헌 카드 인용), `V6`(앞 절 25자 문구 중복), `V7`(금지 상투어), `V8`(표 셀 내부 각주) 전 항목 검출 확인 (`tests/v2_verify_pipeline.test.js`).
2. **검증인의 인용 구절 역검증 (7.3)**:
   - 인용 검증 대화(`X2`)가 문헌 카드의 `abstract`/`aiSummary`에 존재하지 않는 구절을 지어내어 `지지됨`이라고 응답하더라도, 코드가 원문 대조를 통해 강제로 `검증불가`로 격하함을 확인.
3. **합의 규칙 (7.5)**:
   - 결정적 검사 실패 시 AI 검증 결과와 무관하게 무조건 `rework` 판정.
   - 재작성 한도(`maxRework = 2`) 소진 후에도 해결되지 않은 문장은 임의 통과시키지 않고 `〔확인 필요: 사유〕` 표식을 부착하여 `needs_human.md`에 집계함을 확인.

### 2.3 Claude 2차 다듬기 인계 (`P7` / `handoff.js` / `G6`)
1. **인계 묶음 내보내기 (`exportHandoff`)**:
   - `manuscript_v1.md`, `facts.json`, `literature.json`, `outline.json`, `crosswalk.md`, `needs_human.md`, `figures/`, `CLAUDE_HANDOFF_PROMPT.md`, `manifest.json`(SHA-256 해시 포함) 9종 파일 생성 확인 (`tests/v2_handoff.test.js`).
2. **2차 원고 반입 재검증 (`importHandoff` / 게이트 `G6`)**:
   - 다듬기 과정에서 미등록 수치(`99.9m`)나 미등록 문헌(`김가짜 2024`)이 추가된 원고 반입 시 `G6`에서 즉시 거부하고 원문 문장을 보고함을 확인.
   - `facts.json` 또는 `literature.json`이 변조된 경우 `manifest.json`의 SHA-256 해시 대조로 즉시 거부함을 확인.
   - 표현만 다듬어진 유효 원고는 변경 문장에 대해서만 `X1`·`X2`를 재실행한 뒤 최종 `manuscript.md`로 조립됨을 확인.

### 2.4 최종 DBpia AI 문헌 검수 (`P7.5` / `dbpia_review.js` / `G7`)
1. **유적 고유명 제거 및 핵심 학술 주장 선별**:
   - 본문에서 학술 주장 문장을 최대 5건 선별하고, 질의문 생성 시 `가상유적`, `3호` 등 당해 유적 고유명과 개별 유구 번호를 제거하여 학계 일반 편년·계통 논의를 검색함을 확인 (`tests/v2_dbpia_review.test.js`).
2. **상충 검출 및 원고 자동 수정 금지 (`G7`)**:
   - 원고의 연대 비정(예: 기원전 3세기)이 학계 통설(기원후 2~3세기)과 어긋날 때 `상충`으로 판정하고 게이트 `G7`에서 멈추며, 기존 `literature.json`에 없던 신규 문헌을 `L_new1` 보충 후보로 추출함을 확인.
   - 사용자 선택(`rewrite` / `tag` / `ignore`) 전에는 `manuscript.md`를 바이트 단위로도 자동 수정하지 않음을 확인.
